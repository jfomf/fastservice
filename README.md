# Ладно — сервис ремонта в Ярославле: прототип

Прототип сервиса сантехники и электрики под ключ: заявка, смета, назначение мастера и приёмка. Данные остаются в браузере; звонки и оплата не подключены.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер, например `python -m http.server 8000` и откройте `http://localhost:8000`.

## GitHub Pages

Загрузите файлы в корень репозитория и включите **Settings → Pages → Deploy from a branch → main / root**. Пути к ресурсам относительные, сборка не нужна.

## Сценарий демонстрации

1. Выберите услугу, опишите поломку, введите адрес и телефон. При желании добавьте фото.
2. Откройте смету. Цена разбита на работы и материалы.
3. До подтверждения сметы её можно изменить в «Диспетчерской». Затем подтвердите цену как клиент и назначьте мастера. При отказе система назначит следующего доступного.
4. Переведите заявку по этапам до закрытия. В клиентском кабинете посмотрите профиль мастера, фотоотчёт и гарантию, отметьте условную оплату и оставьте отзыв.
5. «Сбросить демо» восстанавливает исходный пример.

Суммы, сроки, профили и отзывы в демо — примеры.

Иконки интерфейса — [Bootstrap Icons](https://icons.getbootstrap.com/). SVG хранятся локально в `assets/icons`, лицензия — в `assets/icons/LICENSE`.

Фотографии — стоковые. [Источники](assets/stock/SOURCES.md).
